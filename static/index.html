COMMAND LINE
PowerShell / Terminal
pip install -r requirements-dl.txt
python scripts/compare_models.py --csv data/Final_data.csv --image-root data --download-thumbnails --max-samples 300 --epochs 3 --batch-size 4

⚑ The pilot downloads only sampled thumbnails from allow-listed YouTube image hosts; you do not need to download/extract the entire 2.41 GB archive for this pilot. Start with 300 rows on a CPU-only laptop. It trains a BiGRU text-only model, CNN thumbnail-only model, MLP engineered-feature model, and multimodal gated-fusion model on the same split. The fusion checkpoint becomes the active inference model after the API restart.

Install locally

About two minutes after the API is running

SETUP
  1. 01
    Start the Veri-Click API

    Run the project using the instructions in README. Keep the local server running on port 8000.

  2. 02
    Open Chrome extensions

    Visit chrome://extensions and enable Developer mode.

  3. 03
    Load unpacked

    Select the project's extension folder. Reload YouTube after the extension loads.

  4. 04
    Scan the visible feed

    Click Scan visible videos. Up to 12 visible cards are checked per scan to avoid excessive requests.

Extension source lives in the ZIP at extension/; see extension/README.md for details.

Safety & boundaries

What the extension does—and doesn't do

✓
Local inference endpoint

Requests go to 127.0.0.1:8000 on your own computer.

✓
Conservative scan limits

Only the visible page cards are considered, with a maximum of 12 per scan.

!
Not a fact-checker

Clickbait-like presentation cues do not prove a video's claims are false.

!
Demo mode is heuristic

Train and evaluate the model on labeled data before academic performance claims.

The extension source is included for local developer loading. It is not published to the Chrome Web Store.
